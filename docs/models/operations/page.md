# Page

Selects a page of groups and its size.

A request can't set both `after` and `before`, and a cursor that doesn't match the request's `sort` isn't accepted.

Defaults to `20`.                                                                                                                   |
| `After`                                                                                                                                                                                   | `*string`                                                                                                                                                                                 | :heavy_minus_sign:                                                                                                                                                                        | A cursor for the page after an earlier response's page. Clients take it from that response's `meta.page.previous` and don't build or change it. The rest of the body must stay the same. |
