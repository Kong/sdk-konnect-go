# AICostStringFilter

Filters a string field. The filter object carries exactly one operator:

- `eq`, `neq`, `in`, `nin`: compare the whole value, case-sensitively.
- `contains`, `ncontains`: look for text in the value, ignoring case.
- `exists`: tests whether the field has a value.
- `and`, `or`: combine nested string filters.
