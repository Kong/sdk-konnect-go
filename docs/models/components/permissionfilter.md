# PermissionFilter

Narrows which permissions match a key. Fields set on the same filter are combined with AND. A filter with no fields set matches every permission.


## Fields

| Field                                                                                                                               | Type                                                                                                                                | Required                                                                                                                            | Description                                                                                                                         | Example                                                                                                                             |
| ----------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| `Resource`                                                                                                                          | `*string`                                                                                                                           | :heavy_minus_sign:                                                                                                                  | Full or partial resource path to match, relative to the organization. A trailing `*` matches any resource under the preceding path. | runtimegroups/*                                                                                                                     |
| `Service`                                                                                                                           | `*string`                                                                                                                           | :heavy_minus_sign:                                                                                                                  | Service the permission applies to.                                                                                                  | reg                                                                                                                                 |
| `Region`                                                                                                                            | `*string`                                                                                                                           | :heavy_minus_sign:                                                                                                                  | Region the permission applies to.                                                                                                   | us                                                                                                                                  |
| `TopLevel`                                                                                                                          | `*bool`                                                                                                                             | :heavy_minus_sign:                                                                                                                  | When true, only permissions on top level resources match; those on nested resources are excluded.                                   | true                                                                                                                                |
| `Actions`                                                                                                                           | []`string`                                                                                                                          | :heavy_minus_sign:                                                                                                                  | Actions to match. When omitted or empty, permissions with any action match.                                                         | [<br/>"read"<br/>]                                                                                                                  |
