# RegistryReferenceAgentFilterParameters

Filter parameters for the agent list endpoint. `name` matches the agent's display name; `slug` is the agent-level org-unique handle; `source_type` is `manual` or `remote`; `labels` filters on agent-level labels by key, e.g. `filter[labels.env]=prod`.
