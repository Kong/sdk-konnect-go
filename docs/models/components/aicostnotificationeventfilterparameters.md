# AICostNotificationEventFilterParameters

Filters on the threshold events' fields. Every filter must match, and a bare value means `eq`.

- `fired_at`: `eq`, `gt`, `gte`, `lt`, and `lte`.
- `budget.id`, `deliveries.status`, and `deliveries.channel.id`: `eq`, `neq`, and `oeq`.

A delivery filter matches an event when at least one of its deliveries matches, and `deliveries.status` and `deliveries.channel.id` together must match the same delivery. Any other filter key fails with `400`. UUIDs compare case-insensitively, and `deliveries.status` accepts only the exact values `pending`, `delivered`, and `failed`.
