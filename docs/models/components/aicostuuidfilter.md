# AICostUUIDFilter

Filters a UUID field. The filter object carries exactly one operator:

- `eq`, `neq`, `in`, `nin`: compare UUIDs, ignoring case.
- `exists`: tests whether the field has a value.
- `and`, `or`: combine nested UUID filters.
