# Provenance

Identifiers from the producer's own systems: the gateway entities and configuration that handled the request, the identity evidence behind `subject`, and identifiers that correlate the event with other data.

At most 64 entries, each with a key of 1 to 128 characters. The keys this schema lists have fixed types. Any other key takes a non-empty string, which the event list doesn't return.
