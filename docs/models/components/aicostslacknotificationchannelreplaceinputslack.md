| `WebhookURL`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | `*string`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | :heavy_minus_sign:                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               | The Slack incoming webhook URL that receives the channel's messages. Because reads never return the full URL, a replacement can omit it, and the channel then keeps its stored URL.<br/><br/>The URL has the form `https://hooks.slack.com/services/<workspace ID>/<webhook ID>/<token>`. Each of the 3 parts is nonempty and contains only ASCII letters, digits, `_`, or `-`. It has no credentials, port, query, or fragment and is at most 2048 characters long. Slack workflow trigger URLs, under `/workflows/` or `/triggers/`, aren't accepted.<br/><br/>The service never logs the URL. Reads return it with `<token>` replaced by `…`. |
