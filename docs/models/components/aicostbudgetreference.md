# AICostBudgetReference

A reference to one of the organization's budgets by its `id`.


## Fields

| Field                                                                   | Type                                                                    | Required                                                                | Description                                                             |
| ----------------------------------------------------------------------- | ----------------------------------------------------------------------- | ----------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| `ID`                                                                    | `string`                                                                | :heavy_check_mark:                                                      | The `id` of the budget, which the budget operations take as `budgetId`. |
